--- Why check 13 reports FAIL on this machine (environment, not code) --------

scripts/validate-class-09.js lines 301-302 execute the suite with a shell that
only exists on Linux/macOS:

    execSync(`node --test --test-concurrency=1 'test/*.test.js'`, {
      cwd: ROOT, stdio: 'pipe', timeout: 240000, shell: '/bin/bash'
    });

On win32 the shell cannot be spawned, so the check fails BEFORE any test runs.
Reproduction of the spawn failure alone:

    node -e "try{require('child_process').execSync('echo hi',{shell:'/bin/bash'})}catch(e){console.log(e.code)}"
    ENOENT

(WSL is not installed on this machine, so the validator cannot be re-run under
a real POSIX shell. The command below is the same suite on the same Node.)
